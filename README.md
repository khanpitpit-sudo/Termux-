# Termux- (Bilingual Guide)

This repository contains a bilingual (English + বাংলা) Termux tutorial page intended to be served via GitHub Pages.

What I added for you:

- `index.html` — bilingual Termux tutorial (English + Bengali).
- `robots.txt` — allows search engines to crawl the site and points to the sitemap.
- `sitemap.xml` — basic sitemap referencing the repository homepage.

How to publish on GitHub Pages (quick steps)

1. Go to the repository Settings → Pages.
2. Under "Source" select "Deploy from a branch" → Branch: `main` → Folder: `/ (root)` and click Save.
3. Wait a few minutes, then open: `https://khanpitpit-sudo.github.io/Termux-`
4. (Optional) If you have a custom domain, add it in the Custom domain field and set DNS:
   - Apex domain (example.com): add A records to GitHub Pages IPs:
     - 185.199.108.153
     - 185.199.109.153
     - 185.199.110.153
     - 185.199.111.153
   - Subdomain (www): add CNAME to `khanpitpit-sudo.github.io`.
