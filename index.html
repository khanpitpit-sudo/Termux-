Termux: What it is and How to Install (Android) — English

Quick guide: install, first commands, common packages and tips.

What is Termux?

Termux is a terminal emulator and lightweight Linux environment for Android. It lets you install packages via pkg/apt, run scripts, and use common command-line tools like git and python.

Install (recommended)

  1. Install from F‑Droid or use the official APK distribution.
  2. Open Termux and run: 
    pkg update && pkg upgrade
termux-setup-storage
  3. Grant storage permission when prompted (needed for accessing files on device).

Useful first commands

pkg update && pkg upgrade
pkg install git
pkg install python
termux-setup-storage

Common packages

  • git — clone repositories
  • python — run Python scripts
  • openssh — SSH server/client

Quick tips

  • Use pkg for most packages; apt also works for advanced tasks.
  • To keep Termux updated regularly run pkg update && pkg upgrade.
  • For persistent services, consider using a VPS — mobile devices are not ideal as 24/7 servers.

Termux: কী ও কীভাবে ইনস্টল করবেন (Android) — বাংলা

সংক্ষিপ্ত গাইড: ইনস্টল, প্রথম কমান্ড, সাধারণ প্যাকেজ ও টিপস।

Termux কী?

Termux হলো Android-এর জন্য একটি টার্মিনাল এমুলেটর ও লাইটওয়েট লিনাক্স পরিবেশ। এতে pkg/apt দিয়ে প্যাকেজ ইনস্টল করে স্ক্রিপ্ট চালানো যায় — যেমন git ও python।

ইনস্টল (সুপারিশকৃত)

  1. F‑Droid থেকে ইনস্টল করুন অথবা অফিসিয়াল APK ব্যবহার করুন।
  2. Termux খুলে নিচের কমান্ডগুলো চালান: 
    pkg update && pkg upgrade
termux-setup-storage
  3. স্টোরেজ পারমিশন দিন (প্রয়োজনে) — যাতে আপনি ডিভাইসের ফাইল অ্যাক্সেস করতে পারেন।

প্রথমে চালানোর কমান্ডগুলো

pkg update && pkg upgrade
pkg install git
pkg install python
termux-setup-storage

সাধারণ প্যাকেজ

  • git — কোড ক্লোন করার জন্য
  • python — পাইথন স্ক্রিপ্ট চালানোর জন্য
  • openssh — SSH কনফিগার করার জন্য

সাধারণ সমস্যা ও সমাধান

  • Permission error: চালান termux-setup-storage এবং অ্যাপের Settings থেকে Storage অনুমতি দিন।
  • Package install fail: ইন্টারনেট সংযোগ চেক করুন, পরে pkg update চালান।
  • Space issue: অপ্রয়োজনীয় ফাইল মুছুন বা SD কার্ড ব্যবহার করুন।

FAQ

Q: Can I run services (like a web server) on Termux?
A: Yes, lightweight servers can run, but mobile devices are not ideal for 24/7 hosting. For production use consider a proper VPS.
