Termux — Quick Start, Setup & Useful Commands (English)

A compact bilingual guide to install Termux on Android, configure it, and start using useful packages and commands.

1. What is Termux?

Termux is a terminal emulator and lightweight Linux environment for Android devices. It provides a package manager (pkg/apt) so you can install common command-line tools like git, python, openssh and many more. Termux is ideal for development, scripting, learning Linux commands, and running small services on your phone.

2. Install Termux

  1. Preferred: Install from F‑Droid (recommended). Play Store distribution has been limited; F‑Droid contains the up-to-date build.
  2. Alternative: Download the official APK from the Termux Github releases if needed.
  3. Open Termux after installation and run the initial update:
pkg update && pkg upgrade
termux-setup-storage

The termux-setup-storage command asks for storage permission and creates a ~/storage directory linking your phone's shared storage.

3. Useful first packages & commands

pkg install git
pkg install python
pkg install openssh
pkg install curl wget

Examples:

# clone a repo
git clone https://github.com/username/repo.git
# run a python script
python3 script.py

4. Working with SSH

Install and configure openssh if you need to connect to servers from Termux or run an SSH server on the device:

pkg install openssh
# Start ssh server
sshd
# Find device IP
ip addr show wlan0

For persistent access set a password with passwd, or use key-based auth with ~/.ssh/authorized_keys.

5. Running small services

You can run lightweight HTTP servers (for testing) or small daemons. Example with Python:

# Serve current directory on port 8000
python3 -m http.server 8000

Note: mobile devices may sleep or close background processes; Termux has options to keep the session alive (Termux:API, Termux:Boot) or use a terminal multiplexer like tmux for session management.

6. Storage and backups

Termux's files are stored in its app directory by default. After running termux-setup-storage you can access shared storage. To back up important scripts, push them to a GitHub repo:

git init
git add .
git commit -m "Initial backup"
git remote add origin https://github.com/you/repo.git
git push -u origin main

7. Troubleshooting & tips

  • If a package installation fails: run pkg update then retry.
  • Storage permission denied: open Android Settings → Apps → Termux → Permissions and allow Storage.
  • Termux seems slow: keep packages updated, use lightweight tools, and avoid heavy builds on-device.

8. Security

Be cautious when running scripts from unknown sources. Use SSH keys rather than passwords where possible and keep packages updated. Avoid exposing services to the open internet unless you know what you're doing.

9. Resources

  • Termux Wiki & Github: https://github.com/termux/termux-app
  • F‑Droid Termux page

১. Termux কী?

Termux হলো Android ডিভাইসের জন্য একটি টার্মিনাল এমুলেটর ও লিনাক্স পরিবেশ। এতে pkg/apt প্যাকেজ ম্যানেজার থাকে, যার মাধ্যমে আপনি git, python, openssh ইত্যাদি ইনস্টল করতে পারবেন। এটি স্ক্রিপ্ট রান, ডেভেলপমেন্ট বা ছোট সার্ভিস চালানোর জন্য উপযোগী।

২. কিভাবে ইনস্টল করব?

  1. সেরা উপায়: F‑Droid থেকে ইনস্টল করুন (প্রস্তাবিত)।
  2. বা অফিসিয়াল APK ডাউনলোড করে ইনস্টল করুন।
  3. ইনস্টল করার পরে Termux খুলে প্রথমে চালান:
pkg update && pkg upgrade
termux-setup-storage

termux-setup-storage আপনার ফোনের শেয়ার্ড স্টোরেজ অ্যাক্সেস দেওয়ার জন্য নির্দেশ করবে এবং ~/storage লিংক তৈরি করবে।

৩. দরকারি প্রথম প্যাকেজ ও কমান্ড

pkg install git
pkg install python
pkg install openssh
pkg install curl wget

কিছু উদাহরণ:

git clone https://github.com/username/repo.git
python3 script.py

৪. SSH ব্যবহার

দুর্লভ সার্ভারে সংযোগ বা ডিভাইসে SSH সার্ভার চালানোর জন্য openssh ইনস্টল করুন:

pkg install openssh
sshd
ip addr show wlan0

অ্যাক্সেস স্থায়ী করতে passwd দিয়ে পাসওয়ার্ড দিন বা কী‑বেসড অথেনটিকেশন ব্যবহার করুন ( ~/.ssh/authorized_keys )।

৫. ছোট সার্ভিস চালানো

টেস্টিংয়ের জন্য ছোট HTTP সার্ভার চালানো যায়:

python3 -m http.server 8000

কিন্তু মোবাইল ডিভাইস ব্যাকগ্রাউন্ডে প্রক্রিয়া বন্ধ করতে পারে—স্থায়ী সার্ভিসের জন্য VPS ব্যবহার করা ভালো।

৬. ব্যাকআপ ও স্টোরেজ

গুরুত্বপূর্ণ স্ক্রিপ্ট GitHub‑এ পুশ করে ব্যাকআপ রাখুন:

git init
git add .
git commit -m "backup"
git remote add origin https://github.com/you/repo.git
git push -u origin main

৭. সমস্যা সমাধান ও টিপস

  • প্যাকেজ ইনস্টল ব্যর্থ হলে: pkg update চালান ও পুনরায় চেষ্টা করুন।
  • স্টোরেজ পারমিশন না থাকলে: Android Settings → Apps → Termux → Permissions এ দেখে অনুমতি দিন।
  • স্পেস সমস্যা হলে অপ্রয়োজনীয় ফাইল মুছুন বা SD কার্ড ব্যবহার করুন।

৮. নিরাপত্তা

অজানা সোর্স থেকে স্ক্রিপ্ট চালাবেন না। SSH‑তে কী ভিত্তিক অথেনটিকেশন ব্যবহার করুন এবং প্যাকেজ আপডেট রাখুন। অনলাইনে সার্ভিস প্রকাশ করার আগে সতর্ক থাকুন।
